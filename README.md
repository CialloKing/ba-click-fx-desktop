# CialloKing/ba-click-fx-desktop Star history data

This orphan branch is maintained by GitHub Actions.

- `stars.csv` stores Star-count history by Asia/Shanghai calendar date.
- `star-history.svg` is generated deterministically from the CSV data.
- GitHub Actions records the repository Star count daily at 03:17 Asia/Shanghai (scheduling may be delayed).
- Bootstrap rows marked `reconstructed` are derived from current stargazers and cannot recover removed Stars.
- Rows marked `observed` contain the API count and its actual observation time; counts may decrease.
- Missed observation dates remain absent; no snapshots are interpolated.
- Both the README chart and CSV link refer to this repository only.

Generated files should not be edited manually.
